## 新增一个作品时

1. 在 `index.html` 对应的 section（开源书 / 开源项目）grid 里加一张卡片（tag: published / writing / project）
2. 在 README 对应表格加一行
3. push → GitHub Pages 自动部署

## 部署

- 站点：https://ai.fly2ai.top（GitHub Pages + CNAME）
- 每个作品独立 repo + 独立域名/页面，此处仅作聚合入口
